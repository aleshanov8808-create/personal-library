# 📚 Personal Library

Небольшое консольное приложение на Python для управления личной библиотекой книг.

## Возможности

- 📚 Просмотр всех книг
- ➕ Добавление книги
- 🗑️ Удаление книги
- 🔎 Поиск книги
- ✅ Отметка книги как прочитанной
- 💾 Сохранение данных в JSON

## Технологии

- Python
- JSON
- Git
- GitHub

## Запуск проекта

1. Клонировать репозиторий
2. Создать виртуальное окружение
3. Запустить программу:

```bash
python main.py
